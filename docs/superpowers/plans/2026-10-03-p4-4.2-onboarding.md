## Ograniczenia globalne

- `to_grant` = pozycje standardu bez **aktywnej** dzierżawy osoby; odebrany dostęp wraca do propozycji.
- `apply` jest idempotentne. `BASELINE_APPLIED` (aktor `ADMIN`, cel `slug:login`, `details.granted = {repo: rola}`) zapisuje się tylko wtedy, gdy coś nadano.
- Nieznany login → 404; admin lub osoba bez zespołu → 422; brak konta admina → 503.
- Adapter tymczasowy nie odbiera ani nie degraduje roli `admin` (brak Last Admin Protection).
