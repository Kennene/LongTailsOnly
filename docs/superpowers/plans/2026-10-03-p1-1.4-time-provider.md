**Goal:** Jedno źródło „teraz” dla całego backendu: zegar UTC z offsetem, który da się przesuwać (time travel) i resetować, oraz test pilnujący, że nikt nie woła `datetime.now()` w logice.

Offset w pamięci procesu. Czas bazowy wstrzykiwany (`base_time_source`) — w testach stały.

**Tech Stack:** Python 3.14 (`datetime.UTC`), pytest.

**Spec:** `docs/adr/0003-simulated-clock-and-time-travel.md`, `docs/adr/0008-time-provider-api-seed-and-demo-reset.md`, Zadanie 2 planu zespołu, `CODING_STANDARDS.md` (sekcja „Zegar symulowany”).

**Zależy od:** 1.1. Niezależne od 1.2 i 1.3 — można robić równolegle.

## Global Constraints

- Interfejs: `get_current_time() -> datetime`, `advance(days: int) -> datetime`, `reset() -> None`, `offset_days: int`. Nie `now()`.
- Zwracany czas jest zawsze aware UTC.
- `datetime.now(` / `datetime.utcnow(` / `date.today(` występują w `app/` tylko w `app/core/time_provider.py`.
- Plik ≤ 300 linii, type hints wszędzie.
- **Nie commitujemy** — kończymy na `git add`.

## Review Focus

1. `advance(0)` albo `advance(-5)` → ma rzucić `ValueError` (podróż w tył tworzyłaby zdarzenia „z przyszłości”; do cofania służy `reset()`).
2. Źródło czasu bazowego zwraca datę bez strefy → `ValueError`, nie ciche przesunięcie o strefę lokalną.
3. Dwa skoki pod rząd (+25, potem +35) → offset kumuluje się do 60 dni (scenariusz demo z `PLAN.md`).
4. Ktoś w serwisie użyje `datetime.now()` → test `test_domain_code_never_reads_system_clock` pada.

`app/core/time_provider.py`:
```python
from collections.abc import Callable
from datetime import UTC, datetime, timedelta


def _system_utc_now() -> datetime:
    return datetime.now(UTC)


class TimeProvider:
    """Simulated clock: real (or injected) UTC time shifted by an in-memory offset (ADR 0008)."""

    def __init__(self, base_time_source: Callable[[], datetime] = _system_utc_now) -> None:
        self._base_time_source = base_time_source
        self._offset = timedelta(0)

    @property
    def offset_days(self) -> int:
        return self._offset.days

    def get_current_time(self) -> datetime:
        base = self._base_time_source()
        if base.tzinfo is None:
            raise ValueError("Base time source must return a timezone-aware datetime")
        return base.astimezone(UTC) + self._offset

    def advance(self, days: int) -> datetime:
        if days <= 0:
            raise ValueError("Time travel only moves forward; use reset() to go back")
        self._offset += timedelta(days=days)
        return self.get_current_time()

    def reset(self) -> None:
        self._offset = timedelta(0)


time_provider = TimeProvider()


def get_time_provider() -> TimeProvider:
    return time_provider
```

```python
import re
from pathlib import Path

APP_DIR = Path(__file__).resolve().parents[2] / "app"
ALLOWED = {APP_DIR / "core" / "time_provider.py"}
FORBIDDEN = re.compile(r"datetime\.now\(|datetime\.utcnow\(|date\.today\(|time\.time\(")


def test_domain_code_never_reads_system_clock() -> None:
    offenders = [
        f"{path.relative_to(APP_DIR)}:{number}"
        for path in APP_DIR.rglob("*.py")
        if path not in ALLOWED
        for number, line in enumerate(path.read_text(encoding="utf-8").splitlines(), start=1)
        if FORBIDDEN.search(line)
    ]
    assert offenders == [], f"Use TimeProvider.get_current_time() instead: {offenders}"
```
